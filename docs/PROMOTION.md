## LinkedIn post draft

I’m sharing a preview of Causal Capybara, a local workspace for applied causal inference.

The screenshots follow a research workflow: start with a guided example, make the study design explicit, inspect diagnostics, compare estimates and uncertainty, and read the assumptions behind the methods.

These examples use simulated data. The displayed estimates were computed by the Python engine; they are demonstrations, not findings from the original published studies.

I’d welcome feedback from applied researchers and teachers: which parts of this workflow would help your research or teaching, and what would you want to see next?

Project repository: [HYHBalci/causal-capybara](https://github.com/HYHBalci/causal-capybara). Access is currently restricted; this preview does not announce a public download.

Prepared on 5 October 2026 from commit `da7de0a36e5426a45cf8aa425b512406ca4fafe2` in [HYHBalci/causal-capybara](https://github.com/HYHBalci/causal-capybara). The captured application UI matches the `v0.1.0` tag. At preparation time, the repository was private and the `v0.1.0` release was a draft.

The application was run in a local browser preview with the real Python analysis engine. The screenshots show actual application screens and computed estimates, with no mocked results. The LinkedIn versions frame those screenshots for presentation; the originals are retained separately for inspection.

The worked examples contain synthetic data generated by Causal Capybara. References to published studies describe the examples’ methodological inspiration; the screenshot values are not those studies’ reported results. Diagnostics and method agreement do not establish that the assumptions needed for a causal interpretation hold.
