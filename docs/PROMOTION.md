## LinkedIn post draft

I’m sharing the v0.1.0 Windows preview of Causal Capybara, a local workspace for applied causal inference.

The screenshots follow one child-development teaching example: read the guided introduction, make measured confounding explicit, inspect overlap, understand an adjustment method, and compare estimates and uncertainty for the average treatment effect among treated children (ATT).

This IHDP-inspired example uses synthetic data generated by Causal Capybara and contains no original study records. The displayed estimates were computed by the Python engine; they are demonstration results, not published findings from IHDP.

I’d welcome feedback from applied researchers and teachers: which parts of this workflow would help your research or teaching, and what would you want to see next?

Public project repository: [HYHBalci/causal-capybara](https://github.com/HYHBalci/causal-capybara).
[Download the Windows x64 installer (.exe, Python included)](https://github.com/HYHBalci/causal-capybara/releases/download/v0.1.0/Causal-Capybara-0.1.0-windows-x64-setup.exe).
The preview installer is unsigned; Windows may show an unknown-publisher warning.

## Version and capture provenance

Prepared on 5 October 2026 from commit `fe62abd0ca40934aa21cd6c0a37a3effd14689a6` in [HYHBalci/causal-capybara](https://github.com/HYHBalci/causal-capybara). The captured application UI matches the `v0.1.0` tag. At preparation time, the repository was private and the `v0.1.0` release was a draft.

The application was run in a local browser preview with the real Python analysis engine. The screenshots show actual application screens and computed estimates, with no mocked results. The LinkedIn versions frame those screenshots for presentation; the originals are retained separately for inspection.

All five screenshots use “Early support and child development”, the built-in IHDP-inspired teaching example with 747 generated observations. It contains no participant records, covariate values, response surfaces, or benchmark splits from the original study. AIPW, propensity weighting, and outcome regression are computed with the Python engine for the same ATT question. References to IHDP describe methodological inspiration; the screenshot values are not published study findings. Diagnostics and method agreement do not establish that the assumptions needed for a causal interpretation hold.
