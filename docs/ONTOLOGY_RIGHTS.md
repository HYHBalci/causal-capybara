# Public knowledge rights policy

The initial package code, project-authored method cards and ontology descriptions
use Apache-2.0. Existing imported Causal Capybara material retains its Apache-2.0
terms and attribution. This is the accepted initial decision in
[ADR 0002](adr/0002-ontology-rights-context.md); CC BY/CC0 in the planning issue
were proposals and were not adopted. A root or directory license cannot override
third-party rights.

Every record, qualified relationship, source/copy and distributable item needs
source identity/version/location, license identifier/URL or explicit unknown
status, attribution, modification status and review basis. Decisions are separate
for `cache`, `display`, `adapt`, `model_context` and `public_export`. A permission
for one use is not a permission for every use. Code, factual metadata, abstracts,
paper text, figures, datasets, original summaries and embeddings do not inherit
one another's permissions.

Publish original explanations, reviewed factual metadata, citations, links and
evidence locators. The initial public pack contains no third-party paper bodies.
Unknown paper rights remain metadata/link-only with protected bodies withheld.
Review the factual metadata's own source/terms independently. API data availability
does not license all publication text: see [OpenAlex API data terms](https://help.openalex.org/api/),
[OpenAlex publication-location licenses](https://help.openalex.org/data/licenses/)
and [Crossref's distinction between factual metadata and abstracts](https://www.crossref.org/blog/crossrefs-board-votes-to-adopt-the-principles-of-open-scholarly-infrastructure/).

When third-party content is later proposed, verify its actual license and
attribution before redistribution. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode.en)
requires attribution and applicable change notices.
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en)
adaptations require separate ShareAlike review. NC/ND content is excluded from the
unrestricted default pack unless an independently valid publishing basis is
reviewed. Unknown rights fail closed for protected bodies. Transformations and
embeddings do not create a new license for their input or output.

[US fair use](https://www.copyright.gov/fair-use/more-info.html) depends on the
specific use and statutory factors. No universal percentage/word-count allowance
licenses a corpus. Any exception-based inclusion requires recorded jurisdiction,
purpose, material, amount, acquisition terms and use-specific review, including
other relevant jurisdictions. Being freely readable, cited, educational or open
source is not blanket redistribution permission.

Private full-text overlays belong outside the distributable pack and are excluded
from public export and cloud model context by default. The compiler/release gate
must reject missing rights/attribution, prohibited bodies, stale evidence and
private overlays. Export a per-record rights manifest and dependency notices.
Corrections/removals invalidate affected snapshots and derived evidence, paths,
context and cursors. Structural validation and licensing checks do not establish
scientific support or human review.

The optional official Python MCP SDK is MIT-licensed; retain its copyright and
license notice when distributing it. Optional R/OpenAlex bridges have separate
code, API and content terms as recorded in [ADR 0001](adr/0001-ontology-transport.md).
