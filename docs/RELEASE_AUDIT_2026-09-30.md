# Release audit — September 30, 2026

Causal Capybara v0.1.0 is being prepared for Friday, October 2, 2026.
The canonical repository and the old-history archive remain private; the release
remains a draft. This audit does not authorize unattended publication.

## Student download and installation

- A prominent direct Windows installer link is provided in the README, installation
  guide, and release notes. It becomes available after public release publication.
- The basic path is download, open setup, install, and launch. Python and required
  analysis packages are bundled. No programming tools are prerequisites for use.
- Developer commands and optional checksum verification are separated from the basic path.
- The installer uses current-user privileges, a Start menu shortcut, and optional
  desktop shortcut and launch on Finish. Microsoft WebView2 is downloaded only if missing.
- The setup publisher and support link identify Yusufhan Balci; VCESR and the canonical repo.
- The installer is unsigned. Windows/browser warnings remain possible; institution
  policy may block installation. A matching checksum does not authenticate a publisher.

## Privacy and dependency audit

The audited baseline source contained 202 tracked files. The scan covered all 279
reachable Git objects, including 9 commits, 1 annotated tag, 57 trees, and 212 blob
versions. All author, committer, and tagger emails use GitHub no-reply identities.
The maintainer's public profile has no public email. Only deliberately fake
example.com test fixtures and generic path examples were found in source.

No credentials, signing keys, project data, embedded datasets, executable archives,
symlinks, or submodules were found in tracked source. Ignore rules exclude local
credentials, environments, signing material, project folders, and build artifacts.
The original repository with private-email history remains in a separate private archive.

## Licensing correction

Apache-2.0 LICENSE, NOTICE, About content, and package metadata identify
**Yusufhan Balci; VCESR** without a private email.

The final audit found that generic SPDX templates omitted upstream copyright notices
for some Rust crates whose published packages did not include their repository's
license files. Exact upstream texts have been vendored with pinned source provenance
and appended to the dependency inventory. All 42 crate omissions were reviewed; the
collector rejects stale revisions, changed texts, and new unreviewed omissions. The corrected candidate must be rebuilt
and its installed notices verified before this item can be closed.
