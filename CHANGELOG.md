# Changelog

Notable user-facing changes are recorded here. Version 0.1.0 is being prepared for
a public release targeted for Friday, October 2, 2026 (Europe/Amsterdam).
Publication is pending; no release is claimed by this file.

## Unreleased — 0.1.0 release candidate

- Added an offline ontological research tree, versioned evidence and rights records,
  reproducible knowledge compiler/index, standalone CLI, local read-only MCP and
  agent skill with client setup and verification reports.
- Added inspectable assistant context, redaction, optional local/cloud help and
  study proposals with desktop approval, revision checks, expiring single-use tokens
  and minimal audit records. AI cannot mark assumptions or diagnostics reviewed.
- Added direct run input/output provenance and separate numerical reproduction
  evaluations with explicit tolerances and an honest ancestry limit.

See the [draft v0.1.0 release notes](docs/RELEASE_NOTES_0.1.0.md).

- Documented command-line source installation from GitHub, with a local browser preview
  and an analysis-only option alongside the Windows installer.
- Initial Windows desktop studio for causal questions, design diagnostics, estimation,
  comparisons, reports, and a browsable method and literature catalogue.
- Windows x64 release candidate with a bundled CPython 3.13.15 runtime and
  packaged analysis dependencies.
- Python engine and optional R adapters; synthetic examples and publisher-hosted
  studies fetched only on request.
- Apache-2.0 licensing for project code and a documented path for contributions and
  private vulnerability reports.

The release's installer contents, supported Windows versions, verification results,
checksums, and known limitations will be recorded with the published release assets.
