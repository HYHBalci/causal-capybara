## Unreleased — 0.1.0 release candidate

See the [draft v0.1.0 release notes](docs/RELEASE_NOTES_0.1.0.md).

- Initial Windows desktop studio for causal questions, design diagnostics, estimation,
  comparisons, reports, and a browsable method and literature catalogue.
- Windows x64 release candidate with a bundled CPython 3.13.15 runtime and
  packaged analysis dependencies.
- Python engine and optional R adapters; synthetic examples and publisher-hosted
  studies fetched only on request.
- Apache-2.0 licensing for project code and a documented path for contributions and
  private vulnerability reports.

The release's installer contents, supported Windows versions, verification results,
checksums, and known limitations will be recorded with the published release assets.
