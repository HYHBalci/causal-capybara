# Security policy

Causal Capybara opens local project files, runs local analysis processes, and can
download study data or packages when a user requests them. Reports about unsafe file
access, local API access, dependency installation, or disclosure of project data are
especially useful.

## Report a vulnerability

Use [GitHub's private vulnerability reporting page](https://github.com/HYHBalci/causal-capybara/security/advisories/new)
if it is enabled for this repository. If the page is unavailable, open a
[public issue](https://github.com/HYHBalci/causal-capybara/issues/new) asking
the maintainers for a private contact channel. Include no exploit details,
private data, or credentials in that issue.

Include the affected version and operating system, steps to reproduce, the expected
and observed behavior, and the potential impact. A minimal synthetic project is
preferable to a real dataset. Maintainers will coordinate a fix and disclosure with
the reporter.

For ordinary bugs and feature requests, use the repository's public issue tracker.
