These are the canonical SPDX License List v3.29.0 text templates for MIT,
Apache-2.0, BSD-3-Clause, Zlib, and MPL-2.0:

https://github.com/spdx/license-list-data/tree/v3.29.0/text

The templates supplement package metadata when an upstream crate does not
ship its own LICENSE file. Package-specific license files take precedence and
are copied verbatim into the release inventory. Causal Capybara's own named
copyright notice remains in the repository's separate LICENSE and NOTICE.
