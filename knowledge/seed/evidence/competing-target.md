# Competing-event handling changes the causal question

SPDX-License-Identifier: Apache-2.0

Original Causal Capybara explanation; agent contextual review only. External publication bodies are not included.

A competing event prevents the focal event. A contrast of focal-event cumulative incidence with competitors present differs from a hypothetical contrast eliminating those events. Treating a competing death as ordinary censoring can silently change the question. Separable-effect targets require meaningful treatment-component interventions and additional identification conditions. A one-event adapter must reject incompatible event coding instead of presenting an unsupported competing-event analysis.
