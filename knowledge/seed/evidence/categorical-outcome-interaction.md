# Categorical-outcome probability heterogeneity

SPDX-License-Identifier: Apache-2.0

Original methodological explanation; agent contextual review only.

A multinomial model represents a probability for each outcome category. Nominal labels are not numerical scores; applying this model to ordered labels does not impose proportional odds or estimate a common ordinal shift. Category probabilities sum to one, so joint tests must account for their dependent contrasts.
