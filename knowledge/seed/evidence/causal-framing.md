# Causal framing requires an identification argument

SPDX-License-Identifier: Apache-2.0

Original Causal Capybara explanation; agent contextual review only. External publication bodies are not included.

A regression coefficient, balanced covariates, a fitted graph or an accurately predicted outcome is not by itself an identified causal effect. Name the intervention, target population, endpoint and contrast, then state which design and assumptions connect them to an observed-data functional. When that argument is unavailable, report an association or model prediction. Computational verification and source links do not establish a study’s exchangeability.
