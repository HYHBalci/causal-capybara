# AFT interactions and marginal effect modification are different tests

SPDX-License-Identifier: Apache-2.0

Original Causal Capybara explanation; agent contextual review only. External publication bodies are not included.

For log T = alpha + beta A + gamma Z + delta A Z + other baseline terms + sigma epsilon with a shared residual distribution, the conditional time factor at Z=z is exp(beta + delta z). Retain modifier main effects and define the reference level. A pooled fit can standardize both treatment predictions over each subgroup target population. Test equality of those survival or RMST differences using their joint uncertainty if that is the question: a zero delta is not the null of equal marginal additive effects. Refit the censored model and recompute standardization in each model-bootstrap replicate.
