# Implementation audits require traceable evidence

SPDX-License-Identifier: Apache-2.0

Original Causal Capybara explanation; agent contextual review only. External publication bodies are not included.

An implementation audit records the authorized revision, code location and observed behavior for each finding, explains the threatened estimand or assumption, and proposes a correction and verification method. Preserve exact data transformations, input hashes, options, randomness and dependency versions. Independent numerical examples, full uncertainty refits and adversarial inputs assess computation. Agreement with a reference calculation or passing software tests does not establish causal identification for the study.

Source context: source:ontology:wilson2017, source:ontology:sandve2013.

This note does not certify a study, a complete implementation, or independent human review.
